Almacenamiento local

Los datos se guardan en este navegador y dispositivo. GitHub Pages publica la aplicación, pero no recibe ni sincroniza los registros. El archivo abierto localmente y la dirección de GitHub Pages tienen almacenamientos separados. Antes de limpiar el navegador o cambiar de instalación, descarga una copia JSON.
